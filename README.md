# All About Agentic AI

A simple single-page React app (built with Vite) explaining agentic AI: what it is, its core components, the agent loop, levels of autonomy, design patterns, use cases, challenges, best practices, and an FAQ.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build in dist/
npm run preview  # preview the production build
```

## Structure

- `src/App.jsx`: page layout and interactive components (agent loop stepper, autonomy slider, FAQ accordion)
- `src/data.js`: all page content
- `src/App.css`: styles
